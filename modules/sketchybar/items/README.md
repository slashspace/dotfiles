# SketchyBar 模块分类

模块由主配置通过 `load_items.sh` 统一加载。

## Active（当前启用）

- `spaces.sh` — AeroSpace 工作区条（0–9、当前工作区应用）
- `calendar.sh` — 日期时间
- `battery.sh` — 电池
- `wifi.sh` — Wi-Fi 状态（点击展开/收起 SSID）
- `volume.sh` — 音量（无背景块，右击切换输出）

## Removed（已移除）

以下模块已从默认配置中删除，以降低维护成本和外部依赖：

- `apple.sh` — 系统菜单
- `spotify.sh` — Spotify 状态与控制
- `brew.sh` — Homebrew 更新
- `dnd.sh` — 勿扰模式
- `github.sh` — GitHub 通知
